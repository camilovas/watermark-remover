Quitar Marca de Agua

App de escritorio para eliminar marcas de agua de imágenes con IA local — sin nube, sin costo por imagen, sin Docker en la máquina del usuario.

Python + PySide6 IOPaint / migan Ollama opcional GPL-3.0
Ver en GitHub Cómo instalarlo Arquitectura

Qué hace

Selección múltiple

Carga varias imágenes a la vez (arrastrar y soltar o diálogo de archivos) y procésalas en lote.

Marcado manual o automático

Dibuja la región de la marca de agua a mano, o deja que Ollama (modelo de visión local) la sugiera.

Inpainting local

El modelo migan (vía IOPaint) reconstruye la región eliminada, con difuminado de bordes para que no se note la costura.

Lotes con progreso

Barra de progreso, cancelación a mitad de camino, y un servidor de inferencia persistente para que cada imagen adicional tarde segundos, no minutos.

Cómo funciona

Cargar imágenes → Marcar máscara → Procesar (local) → Comparar antes/después → Guardar

Stack técnico

  • Python 3.10+
  • PySide6
  • IOPaint (LaMa / migan)
  • Ollama (opcional)
  • PyInstaller
  • pytest + pytest-cov
  • Docker (solo pruebas)

Sin nube, por diseño

Todo el procesamiento de imágenes corre en la máquina del usuario. La única llamada de red opcional es a Ollama (que también puede correr localmente, o en otra máquina de la red) para sugerir automáticamente la región de la marca de agua — y solo se le envía una miniatura reducida, nunca la imagen completa. Si Ollama no está disponible, la app sigue funcionando al 100% con marcado manual.
